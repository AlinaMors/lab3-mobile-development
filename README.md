# Лабораторная работа № 3 — вариант 9

**Исполнитель:** Лорс Алина Абуевна. **Вариант:** 9, «Программист, разработчик на мобильных платформах».

В каталоге `results/` сохранены итоги трёх запусков MapReduce и DuckDB, проверка совпадения частот, обработка ошибки mapper, профилирование, анализ зарплат и регионов. 

При необходимости задайте для клиента адрес и ключи:
```powershell
$env:S3_ENDPOINT = 'http://127.0.0.1:9000'
$env:AWS_ACCESS_KEY_ID = 'rustfsadmin'
$env:AWS_SECRET_ACCESS_KEY = 'rustfsadmin'
```

## Состав решения
- `compose.yaml` — контейнеры RustFS и первоначальной настройки прав.
- `common.py`, `mapreduce.py` — фильтр варианта, чтение S3 по частям, счётчики одиночных навыков, пар и троек. Чанк 2 000 CSV-записей, два процесса и ограниченная очередь.
- `queries.sql`, `duck_query.py` — независимый подсчёт тех же частот средствами DuckDB через S3.
- `run.py` — загрузка исходного CSV в `hh-lake`, проверка данных, три запуска обоих методов, полное сравнение ключей и значений, проверка ошибки mapper, выгрузка результатов.
- `analyze.py` — региональные частоты наборов 1/2/3 и сравнения медианных зарплат.
- `profile_worker.py` — замер времени и пика памяти дерева процессов на Windows. Память контейнера RustFS не входит в замер.
- `test_logic.py` — модульные тесты фильтрации, уникальности навыков, сочетаний и ошибки mapper.
- `results/` — журналы, сводки, данные, результаты трёх запусков и аналитические CSV.


## Контрольные значения

Из 229 388 записей отобрано 3 713 вакансий варианта; 2 743 из них содержат навыки.
| Набор | Различных наборов | Сумма частот |
| --- | ---: | ---: |
| Один навык | 1 007 | 14 904 |
| Пара навыков | 11 950 | 46 696 |
| Тройка навыков | 59 871 | 123 452 |

Полное совпадение частот MapReduce/DuckDB по всем трём размерам наборов и попыткам подтверждается файлом `results/verification.json`. Проверка отказа воспроизводит исключение задачи mapper с повтором, а не аварийное завершение процесса.

## Зарплаты и регионы

Для анализа зарплат отобраны 973 вакансии с сопоставимой зарплатой (RUR, gross=false; середина вилки либо единственная положительная граница). Пары сравниваются с самым частым входящим навыком, тройки — с самой частой вложенной парой. Для анализа эффекта требуется не менее 10 зарплатных наблюдений в наборе и в его базе. Значения показывают ассоциации, а не причинное влияние технологий.

Три региона: Москва, Санкт-Петербург и Новосибирск. Подробные сводки частот навыков, пар, троек и региональных медиан находятся в:

- `results/analysis/regions.csv`
- `results/analysis/region_stacks_1.csv`
- `results/analysis/region_stacks_2.csv`
- `results/analysis/region_stacks_3.csv`
- `results/analysis/pair_effects.csv`, `triple_effects.csv`


## Измерения и оговорки

Другие системы и условия измерения могут давать иные значения. У меня были Windows 10, Python 3.13.3, Docker Desktop, RustFS 1.0.4. По трём попыткам среднее время MapReduce — 12,43 с, DuckDB — 7,20 с. Средний пик памяти MapReduce — 110,6 МиБ, DuckDB — 1 823,7 МиБ. Метод измерения: суммарный RSS наблюдаемого дерева процессов с шагом 20 мс (без памяти RustFS). 

Для диагностического запуска на локальном файле доступен `run.py --local`, но такой запуск не заменяет требуемую работу из S3.
